# 🌐 HTML & CSS — My Learning Journey

Welcome to my **HTML & CSS** repository! 🚀

This repository documents my learning journey in HTML and CSS throughout my four years of B.Tech. It serves as a central place to store my college classwork, self-practice, assignments, problem-solving exercises, projects, and exam preparation materials.

My goal is to build a strong foundation in web development, keep track of my progress, and continuously improve my coding and design skills.

## 📚 What This Repository Contains

- **Classwork:** Code examples, exercises, and concepts covered during college lectures.
- **Self-Practice:** Programs, experiments, and web pages I create independently to strengthen my understanding.
- **Assignments:** Practical tasks and assignments given by faculty.
- **Problem-Solving:** HTML and CSS challenges that improve my logical thinking and implementation skills.
- **Projects:** Web pages, layouts, responsive designs, and other practical projects.
- **Test Preparation:** MCQs, important questions, revision notes, and practice exercises for weekly tests, midsems, and endsems.
- **Error Rectification:** Questions I answered incorrectly in tests and exams, along with their correct answers and explanations, to identify weak areas and avoid repeating mistakes.
